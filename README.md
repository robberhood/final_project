1. Привет! Приложение "scheduler-app" создано для планирования повседневных задач. С его помощью вы можете добавлять/удалять/изменять свои задачи. Вам всего лишь нужно нажать на кнопку "добавить задачу" и в открытом окне заполнить данные. Обратите внимание, что задачи можно отмечать с интервалом повторения, то есть при ее выполнении, задача перенесется на следующую дату по плану. Все задачи отсортированы по дате. Для вашего удобства реализована функция поиска по названию, дате и комментираю в задаче. Удаление/изменение/выполнение задачи - происходит по нажатию маленьких кнопок в правом углу каждой задачи.

2. Задания со звездочкой:
   1. Реализовна возможность запускать приложения с переменными из окружения TODO_PORT и TODO_DBFILE.
      2.Реализована возможность поиска задач по названию и комментарию, а также список задач по определенной дате.
      3.Аутентификация реализована в тестовом режме, в другой ветке на гитхаб. Она работает, но не проходит тесты. Так что здесь только рабочий код.

3. Локально приложение запускается двумя способами:
   1. Командой "go run main.go". В этом случае сервер стартует со стандатрными адресами порта: :7540 и пути к базе данных "scheduler.db"
   2. С указанием переменных окружения "TODO_PORT=9090 TODO_DBFILE="test.db" go run main.go". Например в этом случае сервер стартует на порте 9090 и база данных будет в файле "test.db"
   3. В браузере вы указываете адрес в зависимости от того, каким путем запустили приложение. Если первым, то "http://localhost:7540/", если вторым, то вместо "7540", порт из вашей переменной окружения (в указанном примере это будет 9090, таким образом адрес получится "http://localhost:9090/")

4. Так как реализованы не все задания со звездочкой, параметры при запуске тестов нужно указать такие: "var Search = true"

5. Также реализована возможность запустить приложение через Docker. База данных в этом случае создается в отделтной папке "data", для того чтобы она каждый раз не перезаписывалась. Для запуска нужно выполнить команды:
   docker build -t scheduler-app .
   docker run -d \
    -p 7540:7540 \
    -v $(pwd)/data:/data \
    --name scheduler-container \
    scheduler-app
